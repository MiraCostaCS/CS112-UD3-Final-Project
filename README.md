## Tips
- For multi-screen apps, create the *Singleton* class first (if you didn't in UD2) so that you can setup shared data in your app. Test it with simple data and method calls to ensure it works in two separate screens
- Stay organized and keep it simple! Build basic functionality and looks, you can always add finishing touches after you get it working (e.g., ensure button click pulls data from text fields/components by printing out their values to the console. Then save data in singleton and print it out to ensure its stored correctly. Then update the next screen with the data from the Singleton, etc.)
